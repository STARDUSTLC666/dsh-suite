# Suite 0.2.32 · 邮件工作台同步

2026-10-21，Windows / Node 24.16.0，官方 npm DSH **0.2.1-rc.2**。

- Suite 只将邮件从 0.17.3 更新至 **0.18.0**，同步依赖锁文件与精确版本发布例外；其余 17 个组件版本保持不变。
- **12 项 Suite 测试通过，无跳过**。发布前比对 18 个公开 npm 组件的 SHA-512 / SHA-1，加上本地 Suite 发布包共 19 个完整性记录。
- 官方 CLI 在隔离、无模型密钥的 Web profile 安装 Suite 发布包，18 个组件作为 Suite 的传递依赖安装；profile 不重复启用组件层。逐项核对组件版本及安装锁文件完整性。
- 18 个插件共同启动，注册 **111 个工具、36 个技能**；极简 PTC 在真实 agent 中挂载，模型入口为 `run_code`，SDK 包含可见工具及官方四个定时工具。HyperFrames / Remotion 的技能健康工具执行通过。
- Web 登录 token 交换 **303**、匿名访问 **401**、认证访问 **200**；隔离宿主检查后正常关闭。

邮件自身的 **372 项测试**与官方宿主浏览器操作见 [Email 0.18.0](https://github.com/STARDUSTLC666/dsh-email/blob/main/docs/validation/0.18.0.md)。新增 AgentMail API 与原 IMAP 工作台均使用合成协议服务；真实 AgentMail 权限、额度、投递与远端附件尚未验证。

共同启动与 SDK 检查不等于 18 个插件全部完成真实服务/原生桌面操作。本轮没有重新执行所有组件的完整源码测试与输出契约清单，未配置真实邮箱；Docker、Slack、钉钉的外部服务操作继续搁置。
