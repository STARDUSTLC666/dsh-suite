## 测试与可见操作

Windows 功能测试 1,665 项通过，2 项可选环境测试跳过；另有 Suite 清单和锁文件检查 12 项、Slack 本地 HTTP 协议验收 5 项通过。源码使用官方 DSH `0.2.0-rc.2` 与 `0.2.1-alpha.1` 运行，18 插件共同加载，110 工具、36 技能与极简 PTC 挂载通过；401 未认证、303 换 Cookie、200 已认证页面与进程退出分别核对。Alpha 极简 PTC 挂载包含四个官方定时工具。

可见操作使用隔离资料和官方网页宿主：PPT 编辑、保存及 ZIP 按钮；邮件禁止 Cc、修改草稿、重新预览和一次 SMTP 提交；有效日历创建；两个媒体工作台保存、取消归档、归档与恢复；RSS 分页及真实推荐源预览和订阅；Cite 本地预览、保存、真实 Crossref 补全和下载；SQL 整数与列名、FFmpeg 剪辑、语音合成、技能迁移预览和安装、静态扫描、三轮 Node 测试及服务状态回执。工具选择模型是明确标记的脚本适配器，不作为模型自主调用能力的证据。

实际服务证据：Crossref 返回 Deep learning / Nature / 2015 及作者信息；Edge TTS 返回 19,584 字节、3.264 秒可解码 MP3；Hacker News 返回 30 条并成功订阅。阮一峰源在当前网络返回 HTTP 403，已记录失败并改选其他公开来源；没有绕过站点限制或关闭 VPN。

窄窗口（424×612）日历按钮与聊天发送区域无交集，浮层完整位于视口内；修复后消息可实际发送。极简 PTC 在可见聊天中通过 `run_code` 调用 SQL 返回 `preset_ok = 1`，并列举四个官方定时工具。

## 验收边界

- 本轮没有操作用户的 Electron 原生桌面窗口或重启其进程；网页验收不等于原生桌面全流程验收。
- 本环境 PTC「工作区内修改」被 Windows 沙箱 ACL 授权拒绝（`SetNamedSecurityInfoW / Win32 5 / grantWrite`）。执行成功仅在隔离会话的「完全权限」模式下验证，随后恢复原模式；默认权限下的代码执行仍为受阻，未降低插件或用户日常配置的权限。
- 邮件和 CalDAV 使用隔离的本地协议服务，未发送给真实第三方、未认证外部邮箱 / 日历账号。Email 不提供 Bcc，本轮也没有声称新增 Bcc。
- Slack 缺少真实账号令牌；可见未配置提示与本地协议通过，真实工作区未验收。
- Docker Desktop 的 Linux daemon 未运行；自检如实显示连接失败。容器 argv 行为使用进程协议测试，未修改真实容器。
- Voice 的 ASR 缺少外部服务密钥，使用响应体、超时和取消回归；真实 TTS 单独验收。
- SQL 实际执行 SQLite；MySQL / PostgreSQL 使用适配器协议测试，未连接真实服务器。SQLite 同步查询不能在执行中强行中断，行数限制不等于查询成本限制。
- FFmpeg 流拷贝按关键帧对齐；请求 0.8 秒区间的样例实际为 1.08 秒，不作为逐帧精确剪辑证明。
- 媒体归档回归检查素材和已有成品字节不变；本轮没有重新验收两个独立渲染引擎的完整视频制作。
- GitHub 源码 CI、npm 上传、公开包完整性 / 来源和全新安装是独立证据。HyperFrames 上传成功后的自动公开查询曾超时；后续公开元数据、完整 tarball 和来源提交独立核验成功，没有重复发布。
