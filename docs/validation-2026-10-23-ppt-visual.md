# Suite 0.2.35 / PPT 0.16.0

日期：2026-10-23。组合包仅将 `dsh-ppt` 从 0.15.0 升到 0.16.0，其余 17 个组件版本保持原样。

PPT 可在设置页主动启用视觉检查：通过官方 DSH 模型和图片附件服务看实际 PPTX 渲染，使用受限排版操作另存副本，再渲染并复查新增页面。原文、数值、公式与绑定保留。普通交付不启动此流程。

PPT 已完成 200 项 Windows 测试、官方 DSH 0.2.1-rc.2 Web 实操、官方 LibreOffice Kit 0.1.5 原生渲染、英文深色 390px 窄屏和官方 CLI 独立包全新安装。真实已配置模型对过密页提出 8→4+4 要点拆页，并在副本渲染后复查两页，共两次调用。外部服务失败曾按失败状态保留，未自动再次调用。该样例不证明所有模型或演示稿的判断质量。

新功能未逐项进行桌面原生窗口、实际 PowerPoint / WPS 或 macOS / Linux 的视觉验收；AI 检查与成功渲染不等于人工验收。

组合包验证：12 项测试、冻结锁文件与 18 个组件版本核对通过。官方 DSH 0.2.1-rc.2 的 18 组件契约通过；通过官方 CLI 安装组合包候选 tarball，18 个组件均从公开 npm 作为传递依赖安装，校验值匹配，只启用 Suite 组合层。真实宿主共同启动为 112 工具、36 技能，PTC 预设、完整工具 SDK 与四个官方定时工具可用，认证交换 303、未认证 401、认证首页 200，宿主已正常关闭。

这次共同启动检查不等于 Docker、Slack、钉钉等外部服务的业务验收；这些服务条件仍按原安排搁置。
