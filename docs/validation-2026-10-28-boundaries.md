## 共同加载、界面与输出

- Suite 的 18 组件契约通过：111 个工具、35 个技能、16 个健康结构、19 个输出结构、2 项注册丢失检查；其中 Crossref、子进程版本等夹具明确为模拟，不代表 Docker 或商业服务可用。
- 独立安装方式下，20 个模块在官方 rc.4 都处于 active。真实 agent 回合分别调用 SQL、RSS 和 Flakefinder 写操作，确认错误准确说明 never 策略，没有伪造用户拒绝。Review 的 10 个子任务使用受控本地模型适配器，不代表生产模型的缺陷召回率。
- 九个工作台和 20 个原生详情在真实 Chromium 中操作；检查首屏、更新区域、390px 窄屏和页面异常。多个验收窗口断开后触发未保存保护，按预期显示重新确认入口；未删除该保护。
- HyperFrames 0.8.211 和 Remotion 4.0.539 的实际 MediaWorkbench 各自准备官方环境并导出 720×720、24 FPS、6 秒 H.264 MP4。ffprobe 检查文件与时长，解码第 1、3、5 秒画面核对三张素材顺序及中文。此项直接调用实际工作台类；没有冒充本轮通过原生宿主点击完成导出。
- 自动检查默认开启，**自动安装默认关闭**；更新控件仍位于原工作台或原生详情底部。不强制安装、升级 DSH 或重启用户正在使用的应用。

本文件记录发布前验证。发布后的公开 tarball 完整性、官方 CLI 全新安装和再次原生启动另行核验；不把源码同载测试称作公开包安装验收。
