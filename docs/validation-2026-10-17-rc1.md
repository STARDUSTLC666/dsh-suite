# DSH 0.2.1-rc.1 兼容复查

宿主使用公开 npm `@deepseek-ai/dsh@0.2.1-rc.1`，对应官方标签 [`dsh-v0.2.1-rc.1`](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-rc.1)、提交 `1600d8a1e140dcde43a1a0941940a0480712c011`。环境为 Windows、Node 24，使用独立 profile 和系统 Chrome 无头浏览器；没有切换用户的前台窗口。

## 变化与版本决定

与已验收的 alpha.5 比较，完整官方差异包含 355 个 `package.json`，所有修改都是 `version` 字段。没有应用代码或插件接口变更。现有组件无需为这次宿主更新修改业务代码，也没有新增 npm 版本。

Suite 保持 **0.2.27**，日历 **0.10.4**、邮件 **0.16.3**、RSS **0.6.3**、极简 PTC **0.5.6** 及其余组件的精确版本不变。此次仓库变更只补充兼容记录，并让全新安装验收脚本在隔离 profile 中明确使用公开 npm 源，避免本机镜像同步延迟影响判断；用户的全局配置不变。

## 分别核验的结果

- 19 个包的官方兼容性预检通过；18 个组件的 Windows 自动测试 **1,752 项通过、5 项跳过**。跳过项为 Code Security 的 3 项原生引擎用例、Dream 1 项与 Minimal PTC 1 项，保留原自动测试的跳过记录。
- 另行使用真实 Windows 检查程序完成 Code Security 工作台操作；这与上述离线测试的跳过记录分别保存。
- 通过仓库中的官方 CLI 安装验收入口，从公开 npm 全新安装 Suite 及其 18 个传递组件。版本与 19 个包的 tarball 摘要一致；共同加载 **111 个工具、36 个技能**，完整清单、预设 SDK、调度、HTTP 登录交换、未登录拒绝与进程退出通过。
- 极简 PTC 的实际模型提示词包含当前工具 SDK，模型侧只暴露 `run_code`。函数体模式执行带 TypeScript 类型和工具桥接的代码，返回 42 并显示日志；REPL 模式验证 41 → 42、不同 owner 隔离和释放后清空状态。仅隔离合成会话使用 Full 权限，没有修改用户权限。
- Suite 自身 **12 项测试通过**。

离线契约宿主仅注册 110 个工具、35 个技能；完整宿主加载额外的调度功能，因此清单数不同。不能将两类数量混用。

聊天工具使用标明“本地操作验收（合成）”的适配器选择工具，再交给真实宿主执行。此结果不是远程模型自主选择工具的证明。七个工作台另行核对英文和 390px 布局；表单截图在入场动画结束后复查。日历和邮件缺失账号时的 HTTP 400 属于预期业务拒绝，未计为页面崩溃。

同一已保存会话、同一网页文档中，停用 PPT 后技能从 `/` 菜单消失，启用后返回，没有刷新页面。

安全工作台首次脚本在扫描刷新后直接编辑已折叠的设置而超时；复跑又受到此前合成工程选择的影响。最后改用全新公开安装的 profile，并通过正常控件展开设置，保留全部原扫描和错误处理断言。原始失败输出保留，不将脚本修正记成产品修复。

## 未覆盖与暂缓

Docker、Slack、钉钉按用户要求暂缓业务验收，三个包未修改或发布。共同加载和原样回归不代表已连接这些服务。

本轮没有操作原生桌面窗口，没有使用真实模型、云日历、邮箱、OAuth、数据库服务器或远程语音账号。视频工作台的工程操作不等于最终 MP4 渲染；RSS 没有重测外部来源或无 VPN 网络。

仓库复查时没有未关闭 PR；仍有 RSS #2、HyperFrames #2、Email #19 三个已有 Issue，没有代替使用者发表或关闭反馈。
