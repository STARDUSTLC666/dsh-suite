# 0.2.23：Windows 邮件令牌保护

2026-10-08，收到 Email [PR #22](https://github.com/STARDUSTLC666/dsh-email/pull/22) 后继续复查。该 PR 仅向构建产物增加未使用的加密导入，未实现保护，因此关闭建议 PR，实际修复在源码完成。

固定 Email 0.16.2，其他组件版本保持。Windows OAuth2 token 使用当前用户 DPAPI 加密，旧的有效令牌自动原位迁移；损坏、未知格式、解锁失败或加密不可用时保留原文件，不回退写明文。POSIX 仍使用私有原子文件，不宣称磁盘加密。

邮件完整 Windows 回归 346 项通过，新增存储专项 6 项覆盖真正的系统加密、独立进程解锁、保留账号的迁移与删除、实际密文篡改和加密不可用。正常及失败文案的语言回归通过。隔离官方 Alpha 网页中完成迁移后的三账号展示、删除一账号、剩余两账号保留、英文故障提示和恢复原密文后的页面正常显示。

所有令牌和账号均为合成验收数据；没有使用用户密钥、真实邮箱或前台桌面窗口。详细截图、恢复方法及保护范围见 [Email 0.16.2 验收](https://github.com/STARDUSTLC666/dsh-email/blob/main/docs/validation/0.16.2.md)。

组合清单 / 冻结锁与公开包的独立验证由本次 CI、可信发布及官方 CLI 全新安装记录分别提供；没有将历史组件的测试日期改成今天。官方源码仍为 0.2.1-alpha.1 对应提交，RC2 兼容契约持续保留。原生 Electron 桌面操作、真实微软授权和另一 Windows 账号拒绝解锁未在本轮实测。
