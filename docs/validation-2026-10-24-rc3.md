# Suite 0.2.36 / DSH 0.2.1-rc.3

本版仅将 PPT 从 0.16.0 升级到 0.16.1，其余 17 个组件版本保持不变。

## 已验证

- 使用官方 tag `dsh-v0.2.1-rc.3` 的源码变更与公开 npm `@deepseek-ai/dsh@0.2.1-rc.3` 核对接口。RC.3 的官方 API Key 路由可跟随服务端模型目录；自定义网关与自定义目录仍按官方规则处理。
- 12 项组合包测试、冻结锁文件及 18 个组件版本核对通过。
- 18 个组件在官方 RC.3 上的工具注册、输出 schema、技能和 TypeScript / Python PTC SDK 契约通过。
- 候选 Suite tarball 通过官方 CLI 安装到全新隔离 profile；18 个组件采用已校验完整性的 tarball，其中 PPT 为已经发布的 0.16.1。实际共同启动为 112 工具、36 项技能，PTC 预设与完整 SDK 可用，四个官方调度工具齐全。令牌交换 303、未认证首页 401、认证首页 200，宿主关闭成功。
- 另在本地组件共同启动中加入独立 Review 0.3.0 与 Computer Use 0.1.2，注册 138 个工具、37 项技能，随后关闭。

## PPT 的实际问题与操作验收

公开 0.16.0 的视觉模型选择按目录序号保存；模型下线或重排后，刷新目录可能悄悄选中另一个模型。0.16.1 的视觉检查、AI 预审、模拟答辩改为按提供方和模型 ID 保留选择。原模型不可用时清空并禁用开始，等待重新选择。

PPT 已通过 Windows 完整测试与 6 项新回归、Linux GitHub CI、官方 CLI 候选包安装，以及真实 RC.3 Web 中的三处选择器操作。目录删除、重排、切换模式和纯文字模型排除经过模拟原生适配器验证，模型生成调用为 0。1440×1000 中文及 390×844 英文深色界面操作正常，PPT 窄屏宽度与 scrollWidth 均为 366px，无未捕获页面异常。详细范围见 [PPT 验证记录](https://github.com/STARDUSTLC666/dsh-ppt/blob/master/docs/validation-0.16.1.md)。

## 边界

九个已有设置工作台的入口和渲染已检查；未配置账号的邮件页明确显示配置提示。上述检查不代表所有插件的实际业务流程均已验收，也不代表原有 issue 已解决。

桌面原生窗口、真实 DeepSeek 模型效果和真实 PowerPoint / WPS 未在本轮逐项复验。Docker、Slack、钉钉的真实外部服务验收继续按用户要求搁置。
