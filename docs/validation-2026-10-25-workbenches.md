# 2026-10-25 工作台验收

状态：九个独立版本的 Windows 构建、回归、官方 DSH 0.2.1-rc.3 Web 交互、GitHub CI、可信发布和公开包核验完成。Suite 0.3.0 的官方 CLI 全新安装与 18 组件共同启动通过。

## 方法与边界

使用官方发布的 RC.3 运行时、独立的 DSH_HOME 与无凭据测试资料。Browser plugin 不可用，因此使用后台 Chrome / Playwright；没有切换用户前台窗口。登录交换 303、未认证 401、认证后 200 均通过。

邮件使用受控 AgentMail HTTP 服务；日历只对隔离测试地址替换 DAV 协议传输。插件自身的入口、请求校验、业务处理、存储和原生 DSH 都实际运行。没有真实 AgentMail 邮箱、真实 CalDAV 账号或付费模型调用。Web 结果不等于 Electron 专属窗口、系统权限或账号服务已验收。

## 回归

九仓库合计 1,448 项：1,444 通过、0 失败、4 明确跳过（Security 的三个可选外部条件和 Dream 的压力项目）。每个浏览器包新增真实工厂激活与原生槽位契约回归；移除已经删除的首次引导功能的旧断言，保留并更新重复事件与拖拽安全检查。

九个界面通过宿主中英文切换、浅深色和 390px 首屏检查；各工作台宽度 334px、滚动宽度 334px，宿主页宽度 390px，没有整页横向溢出。最终交互的浏览器运行错误和 console.error 均为零。真实加载后的画面另行查看，不把加载占位算作成品。
